ABOUT / 关于

我们想搭的，
不只是一张服务器列表。

方块周末是一个以周末聚会为核心的 Minecraft 玩家信息页。 我们想把服务器、公告和加入方式放在一个清楚、轻量、手机也能快速打开的地方。

当前站点的服务器名称、群组与联系方式为占位内容。 正式发布前，请替换为真实信息。

01 / STORY

从一个周末开始

很多社区的故事都从一句话开始：“周末有人一起开个服吗？” 然后是一张地图、几位常驻玩家，以及越来越长的群公告。 当信息散落在聊天记录里，新朋友往往要先问很多遍，才能找到适合自己的世界。

方块周末想做的，是把这些入口整理好：每个服务器适合什么玩法、当前是什么状态、 该从哪里加入，以及最近有什么公告。它不替代游戏，也不替代群聊， 只是把最重要的信息放在一个稳定的地址上。

02 / VALUES

我们在意的事

A

信息清楚

版本、玩法、状态和加入方式尽量写明白，让新玩家少走弯路。

B

轻量访问

不依赖重型框架和外部素材，在手机与较慢的网络下也能快速打开。

C

边界与尊重

游戏内可以自由创造，社区里必须尊重他人，保护每个人的隐私与劳动成果。

D

玩家共建

公告、活动和服务器信息由社区维护；发现问题时，欢迎及时告诉管理员。

03 / RULES

社区约定

具体服务器可以补充自己的规则，但以下几条是参与方块周末社区的基本前提。

  1. 尊重每一位玩家。 不攻击、不歧视、不骚扰，也不要在公共频道持续争吵。
  2. 不要破坏他人的劳动成果。 在服务器内遵守建筑保护与领地规则，未经允许不要改动别人的作品。
  3. 不刷屏，不发布违规内容。 包括违法信息、侵权素材、恶意链接以及其他打扰社区正常交流的内容。
  4. 保护彼此的隐私。 不公开他人的真实姓名、住址、联系方式、账号信息或聊天记录。
  5. 遇到问题找管理员。 对处理结果有疑问时，私下沟通比在公共频道反复争论更有帮助。

04 / START

如何参与

1

看看服务器

在首页的服务器导航中确认玩法、版本与状态，选一个感兴趣的世界。

2

加入社区

通过 QQ 群或 Discord 获取最新地址与开服信息。当前联系方式为占位，请先替换。

3

阅读公告并出发

进服前看一眼公告和规则；遇到连接问题，带着版本与错误信息找管理员。
