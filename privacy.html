01 / SCOPE

适用范围

本隐私政策适用于周末愉快站点（域名为 mc.minecraftweekend.cn， 主域名为 minecraftweekend.cn）以及本页面上的静态内容。

本站不提供登录、注册、评论、支付、文件上传或用户生成内容功能。 游戏服务器的连接与游戏内数据由服务器端处理，不属于本站网页的功能范围。 如果你通过外部链接进入 QQ、GitHub 或其他第三方平台，这些平台会按照它们各自的隐私政策处理你的信息。

02 / DATA

我们主动收集什么

本站没有账户体系，也没有表单收集。

页面代码不会主动要求你提交姓名、手机号、身份证件、支付信息或游戏账号密码， 也不会建立访客个人档案。

站内的“复制”按钮只在你点击后调用浏览器的剪贴板能力，把按钮中预设的群号、频道号或邮箱 复制到本地。整个过程在浏览器本地完成，不会把剪贴板内容发送给本站。

本站的交互脚本仅用于：打开/关闭移动端菜单、显示二维码、在滚动时高亮当前导航、 显示当前年份、复制联系方式以及可选的滚动出现动画。这些功能不会创建账号， 也不会把内容写入本站数据库——因为本站没有数据库。

03 / HOSTING

托管与基础访问日志

本站当前使用 GitHub Pages 托管。GitHub Pages 及为其提供基础设施的服务商， 为完成内容分发、连接建立、安全防护和故障排查，可能自动处理以下基础技术信息：

  • 访问者的 IP 地址，以及由 IP 推导出的粗略地理位置；
  • 请求时间、请求路径、访问来源页面（Referer）与响应状态；
  • 浏览器类型、User-Agent、语言与设备等技术信息；
  • 为识别攻击、滥用和异常流量而产生的安全日志、挑战记录与风控信号；
  • 平台为保障服务运行而设置的必要 Cookie 或类似技术。

这些信息通常由托管平台在其基础设施中处理，用于向访问者返回网页、 维持服务安全、统计基础运行指标和排查故障。日志的保存位置、保存期限和处理规则由相应平台决定， 本站无法控制，也无法保证完全不产生日志。

本站没有主动接入独立的第三方访问分析、广告追踪、用户画像、评论区或支付工具。 如果未来启用访问统计或其他处理个人信息的功能，我们会在本页面补充说明， 并在需要时征得同意。

04 / COOKIES

Cookie 与本地存储

本站代码不主动设置用于广告、画像或跨站追踪的 Cookie，也不写入 localStorage 或 sessionStorage。 页面不会弹出“接受所有 Cookie”的追踪授权框，因为没有接入广告或行为分析脚本。

托管平台可能出于安全防护、负载均衡、机器人识别或网络优化设置必要 Cookie。 这类 Cookie 通常不属于可选的营销追踪，其设置行为受平台政策约束。 你可以通过浏览器设置查看、限制或删除 Cookie；限制必要 Cookie 可能导致部分安全验证或访问功能异常。

05 / THIRD PARTY

第三方服务

页面中可能包含指向 QQ 群、QQ 频道、邮箱、GitHub 或其他外部站点的链接， 也包含由 QQ 生成的二维码图片。扫码或点击后，你将离开本站并进入第三方服务。 这些服务可能收集账号信息、设备信息和访问记录。

本站无法控制第三方服务的内容与数据处理行为。请在加入群组、扫码或授权第三方应用前， 先阅读对应平台的隐私政策，并只提供完成交流所必需的信息。

06 / MINORS

未成年人

Minecraft 玩家中可能有未成年人。本站不会主动收集年龄、真实身份或联系方式， 也不会要求访客提交敏感个人信息。

如果你未满 18 周岁，请在监护人知情并同意的情况下参与社区和加入外部群组； 不要在公开聊天中透露真实姓名、住址、学校、手机号或其他可定位到个人的信息。 如果你发现社区中存在不当收集或传播未成年人信息的情况，请通过下方联系方式反馈。

07 / RIGHTS

你的权利与请求方式

由于本站没有用户账户和个人资料页，我们通常无法通过你的访问行为定位到具体个人。 在适用法律允许的范围内，你可以就本站处理个人信息的方式提出询问， 或在合理范围内请求访问、更正、删除或限制处理。

如果你的请求涉及托管平台生成的访问日志、安全 Cookie 或第三方服务数据， 可能需要直接联系相应平台。由于日志由平台控制、保存期限有限， 本站不一定能够代为查询或删除。

提出请求时，请说明具体页面与问题，但不要通过公开渠道发送身份证件、 账号密码或其他不必要的敏感信息。

08 / CHANGES

政策更新

如果站点的功能、托管方式或数据处理实践发生变化——例如启用访问统计、增加表单或接入新的第三方服务—— 我们会更新本页面，并修改顶部的“最后更新”日期。

重大变化会在本页面显著位置说明，必要时通过社区公告同步。 继续使用本站即表示你已阅读更新后的政策；如果你不同意更新内容，请停止使用相关功能。
