01 怎么加入周末愉快？

加入 QQ 群 870774459 即可获取服务器地址；也可以关注 QQ 频道 cdcvk4521a，或直接扫描本页中的二维码。电脑端可以把鼠标移到顶部 「加入社区」，手机端点按同一个按钮查看二维码。

02 加入服务器需要正版 Minecraft 吗？

不需要。服务器不要求正版验证，因此请尽量保护好自己的装备， 谨防同名玩家顶替。遇到可疑情况请在 QQ 群联系管理员。

03 服务器是什么版本和模式？

服务器版本为 26.50，使用生存模式，并且只有一个服务器。 服务器地址和开服安排请在 QQ 群内获取。

04 在中国大陆访问会慢吗？

不会。游戏服务器位于国内，正常网络环境下可以直连。 需要说明的是，本站网页由 GitHub Pages 托管，网页加载速度仍可能受到跨境线路影响。

05 网站是 Mojang 官方站点吗？

不是。周末愉快是玩家自建的服务器与社区页面，与 Mojang Studios、Microsoft 没有隶属或授权关系。页面中的方块图形均由 CSS 绘制，不使用官方素材。

06 会收集我的账号或支付信息吗？

不会。本站没有登录、数据库与支付功能，不主动要求你填写敏感信息。 托管平台可能记录基础访问日志，详情请阅读隐私政策。
